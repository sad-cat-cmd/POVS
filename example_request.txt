Добавление товара
curl -X POST http://localhost:8080/products \
-H "Content-Type: application/json" \
-d '{"name":"Мастер и Маргарита","definition":"Классика русской литературы","price":500,"image":"book.jpg"}'

Получение всех товаров
curl -X GET http://localhost:8080/products

Получение определенного товара
curl -X GET http://localhost:8080/products/{id}

Изменение товара
curl -X PUT http://localhost:8080/products/{id} \
-H "Content-Type: application/json" \
-d '{"name":"Мастер и Маргарита","definition":"Маразм наркомана","price":700,"image":"book.jpg"}'

Удаление товара
curl -X DELETE http://localhost:8080/products/{id}
